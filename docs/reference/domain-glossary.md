# Domain Glossary

Key terminology used across the Photography Reservation System (PRS):

- **Session**: A scheduled photography engagement between a customer and a photographer for a designated package.
- **Slot**: A discrete time window on a specific calendar date allocated for photo sessions.
- **Package**: A photography service offering specifying duration, included edits, and pricing.
- **Add-on**: An optional supplementary service or product (e.g., extra hour, additional edited photo, printed photobook).
- **Proofing**: The client review workflow where customers select favorite shots from raw session proofs before final editing.
- **Watermark**: A semi-transparent overlay placed on proofing images to prevent unauthorized distribution before settlement.
- **Down Payment (DP)**: The initial deposit required to secure and confirm a slot reservation.
- **Blackout Date**: Calendar date or time range during which sessions cannot be booked (e.g., studio maintenance or holidays).
