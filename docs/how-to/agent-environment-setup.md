# How-To: Agent Environment Setup

This guide details the setup of local development and agentic tooling for the PRS project.

## Prerequisites

- Node.js 22 LTS or newer
- npm 10+
- Git

## Tooling & Skills

1. **Context7 MCP**: Use Context7 to retrieve up-to-date documentation for Next.js 15, Prisma, and other libraries before writing new code.
2. **AST Guardrails**: Run `npm run check:guardrails` before opening PRs to ensure adherence to the 6 Mechanical Laws.
3. **Vitest**: Execute tests with `npm run test`.
